Yixian Overlay — README

This nested `yixian-card-counter-damage-calculator` directory is the supported working copy.

Quick start
1. Open a terminal in this folder:

   cd "/path/to/yixian-card-counter-damage-calculator"

2. Install dependencies and run:

   npm install
   npm start

Build distributables
- macOS unsigned:

   npm run dist:mac

- Windows unsigned:

   npm run dist:win

What it does
- Creates a transparent always-on-top overlay window pinned to the right edge of your primary display.
- Default behavior is click-through so the game can receive your clicks.
- Small control buttons in the top-right toggle delete mode, panel visibility, and settings.
- The Electron main process reads the game's real `CardOperationLog.json`, converts it once per second, and writes local derived files for the renderer.
- The renderer reads local `ConvertedHandCard.json` and `ConvertedCardOperationLog.json` generated by this overlay project.
- Runtime state is stored in the app's user-data directory, not in the repo folder.
- Card metadata is bundled locally in `data/card_lib.json` and `data/seasonal_card_lib.json`, so this project does not depend on the main repo at runtime.
- The overlay also captures the game window, detects the 8 played-card slots using leveled templates from `images/`, and runs a local `yi-sim` damage preview for the first 8 turns.

Behavior specifics
- The overlay derives your current hand and tracked card counts from the game's `CardOperationLog.json` via a local converter step.
- Dream and personal cards are hidden from the visible right-side list, but still remain eligible for board detection.
- Each row shows the card name and its tracked deck count from the locally converted operation data.
- Rows sort by phase then name. Phase colors:
  - 1 grey, 2 green, 3 blue, 4 purple, 5 gold
- When delete mode is enabled, hovering a row turns it red and clicking the row hides the card.
- Hidden cards are stored in `overlay_settings.json` under the app user-data directory. If a hidden card is later drawn (hand count increases), it will reappear.
- Board-slot detection only uses template files with numeric level suffixes such as `卡名1.png`, `卡名2.png`, `卡名3.png`. Base art-only files like `卡名.png` are ignored.
- Slot matching is limited to cards currently in hand.
- Production matching uses `rgbMse` with threshold and margin gates. Best candidates below threshold remain empty.
- Damage preview currently runs the detected 8-slot lineup against a passive dummy deck of normal attacks.

Configuration
- The app auto-detects the game data folder on macOS and Windows when `BattleLog.json` or `CardOperationLog.json` is present.
- You can still override that by editing `overlay_settings.json` in the app user-data directory and setting `gamePath` to the folder containing the game's log files.

Notes
- This project is intentionally standalone and does not modify the original `yixian-card-counter` repo.
