# 弈仙牌 Overlay 中文说明

## 简介

这是一个弈仙牌的桌面助手程序。运行时会一直识别你手牌上的卡，并模拟前 8 回合的累计伤害，叠加显示在游戏画面上。

## 下载

**Windows x64 版本：** <https://drive.google.com/file/d/1qva_PhtgsH-lVi544jf_KrhED6pxkmAs/view?usp=drive_link>

下载完是一个 zip 文件，**不需要安装**。任意位置解压（例如 `C:\YixianOverlay\`），双击解压出来的文件夹里的 `Yixian Overlay.exe` 就能运行。

> 第一次运行时 Windows 可能会提示"无法验证发布者"或者"Windows 已保护你的电脑"。点 **"更多信息" → "仍要运行"** 即可。程序没有做代码签名，不是病毒。如果你的杀毒软件把它隔离了，加白名单或者放行就行。

## 系统要求

- Windows 10 或 11，**x64** 架构
- 弈仙牌游戏正在运行
- 建议游戏使用 **窗口化** 或 **无边框窗口** 模式（全屏独占有时识别会出问题）

## 首次使用（重要：必须先校准）

校准只需要做一次，除非以后换游戏窗口大小、换屏幕分辨率，否则就不用再校准了。

1. 打开弈仙牌，进入 **gma8khgq6s** 这一局的 **复盘**：
   - 点击这一局的最后一轮，进入复盘模式
2. 启动 `Yixian Overlay.exe`
3. 点击右上角的 **Set**（设置）按钮
4. 点击列表最上面的 **Calibrate**（校准）
5. 等几分钟，程序会自动找 8 张参考卡的位置和缩放
6. 校准完成后点 **Debug**（调试）。屏幕上会画出每一张卡的检测框 —— 所有框都贴合卡牌就说明校准成功
   - 如果框框位置明显歪了，关掉调试再点一次校准
7. 关掉调试模式，重启弈仙牌，进入正常对局即可使用

## 使用说明

进入战斗后：

- 每张识别到的卡牌**右下角**会出现一个圆形徽标 —— 这是模拟出的**前 8 回合累计伤害**
- 徽标背景变绿色 = 卡牌已识别
- 徽标显示 `--` = 卡牌没识别出来或者还没开始模拟

右上角的工具条：

| 按钮 | 作用 |
|------|------|
| **Del** | 删除模式 —— 点开后再点牌库列表里的某张牌可以把它隐藏（再次抽到会自动显示回来） |
| **List** | 显示 / 隐藏 右边的牌库列表 |
| **Board** | 显示 / 隐藏 棋盘面板 |
| **Set** | 设置面板（详见下方） |

### 设置面板

| 选项 | 作用 |
|------|------|
| **Calibration** | 重新校准（换分辨率、换显示器后必须做） |
| **Damage** | 伤害模拟方式：`Average` 平均（推荐）/ `High Roll` 高骰 / `Low Roll` 低骰 |
| **Cards** | 卡名语言：中文 / English |
| **Card list** | 显示全部手牌 / 只显示剩余 < 2 张的 |
| **Debug** | 调试模式：显示检测框、候选框、识别置信度 |
| **Quit** | 退出程序 |

## 数据存放位置

所有设置都保存在：
```
C:\Users\<你的用户名>\AppData\Roaming\yixian-overlay\
```

里面包含：
- `calibration.json` — 校准数据（卡牌位置、缩放比、个性化角色调整）
- `overlay_settings.json` — 你的偏好（隐藏的卡、语言、伤害模式等）
- `startup.log` — 启动日志（出问题时可以发给作者）
- `overlay_alignment.json` — 最近一次截屏的几何信息（调试用）

**想完全重置程序**：关闭程序，删掉这个文件夹，重新启动即可。

## 已知问题与限制

- **梦幻牌阶段识别**：游戏渲染的梦幻牌和模板图片有微小差异，识别分数会比普通牌低（约 0.65 vs 0.90）。门槛已经调到 0.55，绝大多数情况都能正确识别。如果偶尔识别错家族，重新校准通常能解决。
- **个性化牌几何**：目前只对 **冯许（FengXu）** 做了专门的位置调整。其他角色的个性化牌可能会有 1-2 像素偏移，但通常仍能识别。
- **天赋触发未完全模拟**：模拟器目前只支持部分战斗类天赋（如 Attain Qi、Solitary Void）；非战斗类或未支持的天赋会被跳过，伤害预估可能偏低。
- **dream 牌的等级（phase 1-5）**：通过卡面色彩区域判断，准确度依赖游戏画面清晰度，画面有遮挡时可能出错。

## 故障排查

| 现象 | 处理 |
|------|------|
| 完全检测不到任何牌 | 重新校准 |
| 伤害数字永远是 `--` | 用最新版（旧版打包后无法加载模拟器，新版已修复） |
| 框框位置整体偏移 / 缩放不对 | 重启游戏 + 程序，重新校准 |
| 程序窗口挡住了游戏 | 程序默认是**点击穿透**的，不会拦截游戏输入；如果觉得遮挡视线，可以点 List/Board 隐藏对应面板 |
| 启动后看不到任何东西 | 检查游戏是不是在窗口化模式；检查 `startup.log` 有没有错误 |
| 杀毒软件报警 | 程序没有代码签名，加白名单即可 |

## 反馈

遇到问题想反馈，最有用的两个文件是 `AppData\Roaming\yixian-overlay\` 里面的：
- `startup.log`
- `overlay_alignment.json`

把这两个发给作者，加上你看到的现象描述，就能定位绝大部分问题。
